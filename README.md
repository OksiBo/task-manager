# Task manager

Jednoduchý konzolový správce úkolů v Pythonu. Projekt z kurzu Testing Akademie (Engeto).

Program umí:
- přidat úkol (název a popis),
- zobrazit všechny úkoly,
- odstranit úkol podle čísla,
- ukončit program.

## Požadavky

- Python 3.6 nebo novější (program používá f-stringy)
- žádné další knihovny nejsou potřeba

## Spuštění

```
python task_manager.py
```

Na macOS / Linuxu případně:

```
python3 task_manager.py
```

Program se ovládá číslem volby v hlavním menu (1–4).

## Soubory

- `task_manager.py` – zdrojový kód programu
- `test_cases.md` – testovací případy pro všechny funkce (pozitivní, negativní a hraniční)
